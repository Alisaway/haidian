# 研究叙事与成果导读

## 1. 项目思考

京张铁路创新带不是在既有城市设计上附加几项 AI 设施，而是一次面向 AI 时代的规划范式试验。项目同时面对百年铁路遗产、中关村创新网络、城市更新和快速迭代的智能体技术，因此方案必须先回答证据从哪里来、谁可以改变结论、哪些空间可以试用、何时必须由人接管，以及失败如何停止、清理和复盘。

本方案把《项目研究总纲 V2.0》转译为五个连续动作：建立七类底数与数据图谱；由多 Agent 并行完成问题、目标、对策和反证识别；把工作、生活、学习、公共交往和治理变化转成“稳定公共底盘 + 可逆场景”；用日/周/季/年活动和六段转化链组织长期运营；把同一份判断转成专业报告、公众页面、双语图件和机器可读文件。`verified`、`background`、`design_proposal`、`provisional` 和 `unknown` 不得混写。

## 2. 空间与创新链

三层范围分别承担生态统筹、总体城市更新和重点区域详细设计。总体概念为“京张智脉共生带”：京张铁路遗址公园提供历史与公共空间主轴，众智园 AI 自主创新加速区、北京 AI 原点社区和大钟寺 AI 产业聚集区承担不同的创新接力角色，中关村科技服务翼与小月河场景赋能翼负责专业服务、公共场景和知识回流。该结构是研究关系，不替代法定红线、控规、权属或工程线位。

生态接力遵循“真实问题—研究/开源—资源与责任—受控测试—应用或延期—知识沉淀”的闭环。众智园首先提供可信测试站和全栈接口台；AI 原点社区提供开源共创客厅和成果转化门诊；大钟寺先做需求方评审和单项服务试用。所有资源、活动、算力、机构和运营主体均需要后续授权或实证，不从片区名称推导既成事实。

## 3. 六个首期具象工作点

为避免总体愿景停留在口号，本方案每个重点区选取两个可小样、可观察、可降级的工作点：

| 区段 | 点位 | 首期动作 | 关键人工门 |
|---|---|---|---|
| 众智园 | `P-ZZY-01` 可信 AI 测试站 | 开放验证桌、受控测试舱候选、授权样本和事件清单 | 数据/伦理、设备安全、消防/载体和人工停机 |
| 众智园 | `P-ZZY-02` 全栈接口台 | 项目卡、资源卡、责任人、暂停/恢复/退出账本 | 场景准入、数据治理、停止恢复与规划采纳 |
| AI 原点社区 | `P-ORI-01` 开源共创客厅 | 免费人工前台、每周开源桌、纸质资源目录、贡献与纠错板 | 许可、署名、内容公开/撤回和无障碍 |
| AI 原点社区 | `P-ORI-02` 成果转化门诊 | 问题卡、证据成熟度分诊、IP/法务/测试转介 | 需求真实性、权属、保密和专业意见 |
| 大钟寺 | `P-DZS-01` 智能原生试用廊 | 自愿商户单项服务、普通服务保底、人工客服和退出清理 | 消费者知情/拒绝、数据和公平性 |
| 大钟寺 | `P-DZS-02` 需求方评审厅 | 纸质四象限步行核查、无障碍任务走查和问题派单 | 交通、无障碍、路权、站口和运营责任 |

六个点当前均为研究型候选，空间状态保留为 `provisional_area_text_only`、`text_only_pending_official_anchor` 或 `non_spatial_service_with_text_only_offline_desk`。不指定真实楼宇、坐标、商户、站口、道路红线、建筑面积或批准用途。

## 4. 数据、运营与成果表达

研究底座目前形成 33 条文化节点、16 条权威文化补充来源、7 个全球案例、24 条案例证据、13 张场景卡、8 类用户与旅程、19 项活动、15 项父指标、15 项专业深度合同、9 层 GeoJSON 以及 20 个 JSON/29 个 CSV 研究文件。指标基线、运行实例和真实运营事件仍为 `unknown`、`null` 或空数组，不能被解释为“没有问题”或“已经运行”。

多模态成果采用同源派生：来源/主张/缺口台账 → 关系图谱 → JSON/CSV/GeoJSON → 证据图和场景卡 → 双语离线 HTML → A3/A0 与 PNG → manifest、哈希、版权和自检。公众可以看到“这是什么、是否已建、我能否拒绝、如何人工咨询”；专业人员可以追溯来源、公式、限制和复算；机器读取稳定 ID 和状态。高风险规划审批、工程安全、医疗、教育、投资、采购和公共荣誉一律转人工或拒答。

## 5. 当前成果边界

本叙事与 `proposal.md`、GeoJSON、指标、矩阵、双语图件、A3/A0 PDF 和离线 HTML 同源。正式包当前为 `ready_for_review`，本地结构、双语、视觉、专业证据和自检链已通过；这不等于组织方正式评分、PR 合并或 100 分。官方正式边界、现场测绘/访谈、专业签署、运行主体和真实试点实例仍是下一阶段外部输入；一旦取得正式几何，必须整体替换 9 层空间数据并重算指标、图件、HTML、PDF、manifest 和全部校验。
