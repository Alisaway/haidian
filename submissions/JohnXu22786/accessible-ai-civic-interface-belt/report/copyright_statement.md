## Privacy and human review

The concept permits only anonymous aggregation, keeps a human in key decisions, and prohibits excessive monitoring. The package contains no personal data, face, voiceprint, continuous trajectory, private API response, or private interface. Any future data connection must be separately cleared, minimized, documented, deletable, and opt-out capable.
