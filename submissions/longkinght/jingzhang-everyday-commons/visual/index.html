01 / DUAL ORIGIN

京张的下一次“开路”，是让公共智能拥有可见入口、人工等价路径与可审计退出。

事实锚点

1994年4月20日，NCFC通过64K国际专线实现中国全功能接入互联网。

设计隐喻

64KB、8×8、Demoscene与 ROM / RAM / I/O，把有限资源下的索引、复用和公开接口变成可读的空间语法。

64K / MVP

最小可行单元

64KB、64㎡与64小时只作为可选原型尺度：用最小资源验证一项公共体验，不等于建设面积或活动承诺。
